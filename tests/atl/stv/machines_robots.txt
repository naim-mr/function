Machines & Robots -- original model (STV built-in benchmark)
===========================================================

Reference
---------
Tool : STV (StraTegic Verifier), W. Jamroga, D. Kurpiewski, et al.
       https://github.com/blackbat13/stv   (newer: blackbat13/stv_v2)

Informal model
--------------
A factory line with several machines and a team of robots. Each robot is an
agent that, every round, may operate a machine (produce one item), repair a
machine, or move. Machines may break down nondeterministically
(environment). Robots have imperfect information about machine states.

State (numeric): items produced so far, and the broken / working status of
the machine(s).

Strategic property (the one encoded for FuncTion)
-------------------------------------------------
The coalition of robots can reach a production target despite breakdowns:

    << robot_1, ..., robot_k >>  F  ( produced >= target )

A typical winning strategy lets one robot repair while another produces.

C transcription: ../stv/machines_robots.c
  (target = 4; one robot repairs, the other produces each round)

Parameterisation for a benchmark family
---------------------------------------
Vary the number of robots / machines and the production target.
