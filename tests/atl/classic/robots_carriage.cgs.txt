Two Robots and a Carriage -- concurrent game structure (CGS)
===========================================================

Reference
---------
S. Demri, V. Goranko, M. Lange.
"Temporal Logics in Computer Science", Cambridge University Press, 2016.
Chapter 9, "Alternating-Time Temporal Logics" -- canonical CGS example.
https://www.cambridge.org/core/books/temporal-logics-in-computer-science/

(The example also appears in V. Goranko's lecture notes on logics for
strategic reasoning; it is the standard illustration of concurrent game
models for ATL.)

Informal model
--------------
A carriage stands on a CIRCULAR track with 3 positions: 0, 1, 2.
Two robots, robot1 and robot2, are on opposite sides. At each step each
robot independently chooses one of two actions:

    push   |   wait

The carriage moves ONLY IF EXACTLY ONE robot pushes:
  - only robot1 pushes  -> clockwise        (pos := pos + 1 mod 3)
  - only robot2 pushes  -> counter-clockwise (pos := pos - 1 mod 3)
  - both push, or both wait -> the pushes cancel, the carriage stays put.

Concurrent game structure:
  - agents = { robot1, robot2 }
  - states Q = { 0, 1, 2 }
  - each robot's moves = { push, wait }
  - delta is the "exactly one pusher moves the carriage" rule above.

Strategic properties
--------------------
The coalition of both robots can drive the carriage to a target:

    << robot1, robot2 >>  F  (pos = target)   -- TRUE

A single robot CANNOT force it: whatever robot1 does, robot2 has a
counter-strategy keeping the carriage still (push when robot1 pushes, wait
when robot1 waits, so the move is always cancelled or never initiated):

    << robot1 >>  F  (pos = target)           -- FALSE

This is the canonical illustration that coalitions strictly increase
strategic power.
