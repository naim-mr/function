Train Gate Controller -- game structure (AHK Example 2.2, Fig. 1)
================================================================

Reference
---------
R. Alur, T. A. Henzinger, O. Kupferman.
"Alternating-Time Temporal Logic". Journal of the ACM 49(5):672-713, 2002.
https://www.cis.upenn.edu/~alur/Jacm02.pdf  (Example 2.2, Figure 1)

This is the paper's running example: a SINGLE train entering a railroad
crossing, modelled as a TURN-BASED synchronous game structure (NOT a
concurrent one). Exactly two players.

Players
-------
  k = 2.  Player 1 = the train,  Player 2 = the gate controller.

Atomic propositions
-------------------
  Pi = { out_of_gate, in_gate, request, grant }

States  Q = { q0, q1, q2, q3 }  with labelling pi
-------------------------------------------------
  q0 : { out_of_gate }            -- train is outside the gate
  q1 : { out_of_gate, request }   -- train has requested to enter
  q2 : { out_of_gate, grant }     -- controller has granted permission
  q3 : { in_gate }                -- train is in the gate

Turns and transitions (di = number of moves of player i)
--------------------------------------------------------
  q0 : train's turn  (d_train=2, d_ctr=1)
        move 1 -> stay in q0 (out)        move 2 -> request, go to q1
  q1 : controller's turn (d_train=1, d_ctr=3)
        move 1 -> grant, go to q2         move 2 -> deny, go to q0
        move 3 -> delay, stay in q1
  q2 : train's turn  (d_train=2, d_ctr=1)
        move 1 -> enter the gate, go to q3   move 2 -> relinquish, go to q0
  q3 : controller's turn (d_train=1, d_ctr=2)
        move 1 -> keep the gate closed (stay q3)  move 2 -> reopen, go to q0

So q1 and q3 are controlled by the controller; q0 and q2 by the train.

Classical ATL properties on this structure
-------------------------------------------
  << train >>        F in_gate     -- FALSE: the train alone cannot force
                                      entry (the controller may deny/delay).
  << train, ctr >>   F in_gate     -- TRUE : together they reach the gate.
  << ctr >>          G !in_gate    -- TRUE : the controller can keep the
                                      train out forever.
